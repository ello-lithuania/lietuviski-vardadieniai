# naujagimiu-vardai

Populiariausi Lietuvos naujagimių vardai (2024 m., VĮ Registrų centro atviri duomenys) – maža Python biblioteka ir komandinė eilutė.

**Krikšto vardai, jų reikšmės ir krikštynų dovanų idėjos – [krikstynudovana.lt](https://krikstynudovana.lt/kriksto-vardai/).**

```
$ naujagimiu-vardai --top 3
Mergaitės: Sofija, Amelija, Emilija
Berniukai: Markas, Benas, Jonas

$ naujagimiu-vardai --vardas amelija
```
